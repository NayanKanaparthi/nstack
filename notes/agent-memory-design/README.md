# agent-memory-design: notes

The record behind the [agent-memory-design](../../skills/agent-memory-design) skill.

- `NOTES.md`: the research the skill started from, with sources.
- `DECISIONS.md`: the design decisions the sources didn't settle, what was chosen, and which ones are our own judgment.
- `reviews/`: what each independent review found.
  - `round-1.md` to `round-3.md`: the first three reviews of the skill. All three failed it.
  - `build-1-memory-review.md` and `build-2-memory-review.md`: the review step run on two agents built from scratch with the skill (a weekly status poster and an interview scheduler). Both reviews failed the built agent and found real bugs the builder had missed.
  - `build-2-review-notes.md`: what that second review showed was missing in the skill itself.
  - `round-5-final-review.md`, `round-6-recheck-items.md`, `round-7-recheck-items.md`: the final review and the items re-checked after each fix. The last re-check passed.

Reviewers never saw the build they were checking. Nobody who built something signed it off.
